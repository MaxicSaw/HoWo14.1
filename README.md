## HomeWork
# Парсер товаров и категорий

Проект предоставляет инструменты для работы с товарами и категориями:

## Основные возможности

1. **Классы данных**:
   - `Product` - товар с:
     - Приватным атрибутом цены с валидацией
     - Подтверждением при понижении цены
     - Автоматическим объединением дубликатов
   - `Category` - категория с:
     - Приватным списком товаров
     - Строгой типизацией добавляемых товаров
     - Автоматическим подсчетом продуктов
     
2. **Функционал**:
   - Загрузка данных из JSON-файла (`load_data_from_json()`)
   - Геттеры для безопасного доступа к данным
   - Валидация данных при создании и изменении
   - Автоматическое обновление счетчиков:
     - `Product.total_products`
     - `Category.category_count`
     - `Category.product_count`

3. **Тестирование**:
   - 100% покрытие основных сценариев
   - Проверка:
     - Инкапсуляции атрибутов
     - Валидации входных данных
     - Работы с пользовательским вводом
     - Обработки ошибок

## Использование

1. Создайте JSON-файл с данными о категориях и товарах
2. Используйте функцию loader_data для загрузки
```python
from src.loader import loader_data

categories = loader_data('products.json')
```
3. Работайте с полученными объектами Category и Product
```python
# Создание товара
new_product = Product.new_product({
    'name': 'Новый товар',
    'description': 'Описание',
    'price': 1500,
    'quantity': 10
})

# Добавление в категорию
categories[0].add_product(new_product)

# Изменение цены с подтверждением
categories[0].products[0].price = 2000  # Запрос подтверждения при понижении
```
